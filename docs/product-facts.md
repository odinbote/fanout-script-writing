## What is inside each

**System Design.** "Learn the building blocks, then work through systems and company cases." Modules: Foundations;
APIs, services and protocols; Data modeling and SQL; NoSQL, partitioning and IDs; Caching and fast reads;
Distributed coordination; Storage engines; Async work and streams; Search and retrieval; Analytics and sketches;
Realtime, social and feeds; Geo, matching and recs; Media, files and CDN; Reliability and operations; three
modules of designs; Engineering case studies. Shows how systems at Netflix and Uber work, with interactive animations.

**ML Math.** "Connect sets, linear algebra, calculus, and probability to machine learning." Modules: Sets, Logic,
Linear systems, Spaces, Spectral, Projection, Low rank, Applications (linear regression, PCA), Calculus,
Probability, Joint random variables, Inference. Interactive checks throughout.

**AI Research.** "A structured path from math fundamentals to building LLMs from scratch." Modules: Math
Fundamentals; Core AI Intuitions; PyTorch Fundamentals; TensorFlow Fundamentals; Neural Network from Scratch;
Transformers; Reinforcement Learning; LLM From Scratch; Write Research Paper; How to Fine-Tune Models; MLOps;
Bonus. Landmark papers in reading order; an idea is explained before you read the paper (the homepage shows a
reading note on "Attention Is All You Need").

**Inference Engineering.** "For backend, ML, and platform engineers moving from model demos to production
traffic." Inference fundamentals and a first language model, then KV caches, batching, quantization, serving
runtimes, distributed execution, benchmarking and observability. Latency and cost budgets.

**AI Engineering.** "Learn AI engineering from first principles."

| Module | Lessons |
|---|---|
| 01 Start here: the AI engineering map | What AI engineering is; the stack; one model call, end to end |
| 02 Embeddings and retrieval | Data to vectors, semantic space, vector compression, vector search, indexing, inside a vector database |
| 03 LLM foundations | What a language model does, how it learns and generates text, making a model useful, retrieval-augmented generation |
| 04 LLM internals | Positional embeddings, attention, transformer architecture, KV cache |
| 05 Transformer walkthrough | Masked attention, multi-head attention, tracing shapes |
| 06 LLM optimizations | Paged attention, mixture of experts, FlashAttention |
| 07 Model tradeoffs | Quantization, sparse attention, teaching a smaller model, speculative decoding |
| 08 Reasoning and verification | Chain of thought, tool usage, tree of thought, diagnosing reasoning failures |
| 09 MCP and agents | Context engineering, the agent loop, Model Context Protocol, an agent plan you can check |
